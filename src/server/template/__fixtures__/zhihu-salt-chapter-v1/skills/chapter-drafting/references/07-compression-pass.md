# 第 7 轮：功能压缩

本轮唯一任务是删除或合并无功能表达。不要新增事实、动作、对白、情绪和场景，不重构已经通过的变化链。

逐句问：它是否推进事实、选择、关系、信息或状态，或者让人物/读者情绪压力发生可辨认变化？两者皆无就删除或并入有效句。每个词也必须服务其所在句的作用。

优先删除：

- 已经成立的重点被同义解释、动作或意象再次兑现；
- 只搭台的“我意识到”“这意味着”“就在这时”；
- 只服务气氛、修辞、顺口或静态画面的表达；
- 不改变对象、强度、证据、关系、风险或后果的重复加压；
- 能删去而不影响下一动作、人物关系、信息判断、读者压力、人物声音和状态交接的段落。

压缩不得破坏高权重闭环和情绪链。短段用于阅读呼吸，不把正文切成电报式碎句，也不把冲突、质问、反驳、承认、决定或情绪宣泄压成“争吵了一番”。篇幅不足时，只恢复已经授权但被压掉的回应、反馈、选择、状态变化或余波，不填充景物、回忆和新事故。

输出最终 `chapter-draft.md`，只含一个一级标题和正文。
