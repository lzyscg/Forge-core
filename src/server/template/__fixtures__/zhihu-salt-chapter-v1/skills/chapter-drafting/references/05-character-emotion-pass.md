# 第 5 轮：人物与情绪

本轮唯一任务是让人物行动、对白和情绪压力成立。不要重排情节，不补世界事实，不做压缩。

逐个重要人物检查：

1. 此刻想得到什么、在防什么、采取什么策略；
2. 每句对白在施压、回避、试探、求证、切割、诱导、反击或决定什么；
3. 对方的回应是否改变下一轮策略，而不是机械问答；
4. 重要情绪是否形成“具体刺激 → 克制或阻滞 → 可见外化 → 宣泄或有依据的延期 → 最短余波”；
5. 读者压力是否积累、转移、释放或明确延期；
6. 人物声音是否保留身份、关系和叙述偏见，是否被统一润色成理性书面语。

动作只让情绪可见，不能自动证明未授权的内心含义。避免批量使用握拳、发抖、红眼等通用外化；动作与话语已经表达同一情绪时，让对白进一步改变对象、关系或决定，不要同义翻译。

输出完整 `chapter-draft-v3-character.md`。只改人物策略、对白和情绪链相关句段。
