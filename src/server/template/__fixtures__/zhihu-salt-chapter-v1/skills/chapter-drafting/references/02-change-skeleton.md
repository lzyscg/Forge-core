# 第 2 轮：变化骨架

本轮唯一任务是搭建“变化”，不写完整正文，不追求文风，不做逐句删改。

输出 `chapter-change-skeleton.md`：

1. 先用一句“从……到……”写出本章唯一总变化；
2. 按执行包顺序拆成场景或功能单元；每个单元写起始状态、触发、人物回应、反馈、新状态；
3. 标出单元之间必须存在的因果或状态连接，连接只交代读者理解下一步所需的信息；
4. 标出核心单元、连接单元和承载声音/情绪的单元；
5. 标出必须细写、可以概述、必须直接写出的对白及禁止补设的空白；
6. 核对每个 P0/P1 只有一个主要兑现位置，章尾落在执行包允许的状态。

高权重单元不能只有结果。它至少要让读者看见刺激如何落到人物身上、人物为何采取当前行动、行动得到什么反馈、反馈如何改变下一反应。

已关闭事件只作为章首状态，不重新演一遍。若单元无法在授权事实内完成闭环，退回第 1 轮或执行包，不自行发明发现方式、工具、程序、证据或时间。
