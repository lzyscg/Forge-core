# 盐选短篇单章正文写作

## 核心原则

正文节点是一个持续会话中的 Agent，不是一次 API 调用。一次会话只处理一个章节；同一会话用多轮小任务把该章从执行包推进到候选正文。

每轮只有一个注意力目标。不要在写骨架时润色，不要在人物轮检查硬事实，不要在信息轮重做情绪，不要在压缩轮新增剧情。上一轮已经成立的内容默认冻结，当前轮只修当前维度。

完整标准不再同时塞给每一轮。进入哪一轮，只读取该轮对应的 reference；不要预载后续轮次。这样保留全部质量标准，同时避免模型在一次响应中兼顾相互竞争的要求。

## 输入边界

只使用：

1. 当前章节执行包；
2. 同一正文 Agent 会话内已经产生的本章中间产物；
3. 可选的当前章旧稿与安全返修单。

不要读取或推断完整大纲、未来章节、结局解释和完整历史正文。执行包是本章的全局事实边界；包外空白不是创作邀请。姓名、身份、关系、专名、数字、程序、前史、物件和跨章状态不得自行补全。

执行包授权“提到某个结果”不等于授权展开这个结果的执行过程。若当前章只用一句概述、决定或预叙指向另一章拥有的事件，正文必须保持相同抽象层级；不得把后章拥有的动作顺序、对白、物件、数字和状态变化提前搬入当前章。章节所有权优先于“信息在全篇里为真”：全局真实但不属于本章细写位置的内容，仍不能在本章展开。

## 生产目标

先完整兑现本章重点，再删除无功能文字。正文中的表达必须至少承担一种作用：

- 推进事实、动作、选择、因果或状态；
- 改变关系、权力、信息或人物知识；
- 积累、释放或转移人物与读者的情绪压力；
- 完成必要的声音、方位、交接、悬念、喜剧落点或结构回声。

“更文学”“更有画面”“更顺”不能单独构成保留理由。但删除测试必须晚于重点闭环：高权重重点先保有触发、回应、反馈和新状态，情绪重点还要保有刺激、外化或余波，不能为了短而压成事件清单。

## 同一会话的七轮工作流

自动化生产必须保存每轮产物。普通交互可以只向用户展示最终正文，但内部仍按顺序完成；不得在一轮里合并多个任务。

1. **重点与权限**：读取 [01-focus-contract.md](references/01-focus-contract.md)，输出 `chapter-focus.md`。只确定本章要写什么、各重点占比和可用事实，不写正文。
2. **变化骨架**：读取 [02-change-skeleton.md](references/02-change-skeleton.md)，输出 `chapter-change-skeleton.md`。只搭建场景变化与因果连接，不写成文。
3. **正文展开**：读取 [03-prose-render.md](references/03-prose-render.md)，输出 `chapter-draft-v1.md`。只把已通过骨架写成可读正文，不承担终审。
4. **因果校正**：读取 [04-causality-pass.md](references/04-causality-pass.md)，输出 `chapter-draft-v2-causality.md`。只修触发、回应、反馈、转场和章尾状态。
5. **人物与情绪**：读取 [05-character-emotion-pass.md](references/05-character-emotion-pass.md)，输出 `chapter-draft-v3-character.md`。只修人物目标、对白策略、情绪外化和读者压力。
6. **信息与连续性**：读取 [06-information-continuity-pass.md](references/06-information-continuity-pass.md)，输出 `chapter-draft-v4-integrity.md`。只修事实授权、知识边界、时空、物件和章节边界。
7. **功能压缩**：读取 [07-compression-pass.md](references/07-compression-pass.md)，输出 `chapter-draft.md`。只删重复、解释、空转和无目的表达，不新增事实或重构情节。

任一轮发现上游产物不能支持当前任务时，停止当前轮并回到最早责任轮：重点或事实缺失回第 1 轮；变化链不成立回第 2 轮；仅正文没有兑现则回第 3 轮。不要在下游临场补设定。

## 会话与产物纪律

- 七轮必须属于同一个正文 Agent 会话，不能把每一轮伪装成互不相干的一次调用。
- 每轮可读取本会话的历史，但只允许修改当前轮声明的维度。
- 每轮输出一份可保存的完整服务产物；不靠模型声称“已检查”。
- 转入下一轮前，运行器先确认当前产物存在且非空；程序能确定的字数、标题、引号、重合和差异检查交给脚本。
- 作者会话内的七轮不能代替 `zhihu-salt-chapter-packet` 的独立审核，也不能自行宣布交付通过。
- 独立审核必须检查章节所有权和展开等级，不能因 P0 关键词已出现或事实全局真实就判通过。

## 返修

收到安全返修单时读取 [08-targeted-repair.md](references/08-targeted-repair.md)。返修仍在一个独立返修 Agent 会话中分轮进行，但只启用与返修单命中的维度；例如只有事实越界，就执行“信息与连续性”轮，不重跑人物情绪轮。

## 最终输出

只交付一个一级标题和一份正文，不输出多个候选、计划、自检、字数报告、未来预告或创作说明。自动化生产保留所有中间产物，供总控追溯与打回。
