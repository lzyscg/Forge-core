# 自适应知乎短篇正文写作

## 核心目标

复现参考文本的叙事效率、阅读动力和表达距离，不复用其人物、设定、独特句子或反转答案。

正文里的每个表达单元都必须服务于当前故事需要的功能。功能可以包括：

- 叙事推进与因果连接；
- 人物塑造与选择；
- 关系建立、变化或兑现；
- 情绪、感官与主观体验；
- 场景定位与氛围变化；
- 信息、线索与认知更新；
- 世界规则与必要背景；
- 喜剧、悬念或阅读节拍；
- 叙述声音与人物语言；
- 主题意象与结构回声。

功能集合由本次任务决定，不要求每篇故事同时具备以上各项，也不把“情节或情感”当成唯一保留资格。删除一个词、停顿、重复或细节后，只要必要功能、人物声音或目标节奏受损，就保留或改短；全部不受损时才删除。

惜字不是把故事压到最短，而是先把应该发生、应该感到和应该被理解的内容写完整，再只让有作用的文字留下。

除非用户要求说明，交付只包含正文。

## Agent 分步写作原则

## 生产优先级：重点信息与句子目的

正文首先服务本章重点信息，不先服务解释、铺陈或独立的表达欲。动笔前必须为每个 P0/P1 制定本章有效表达的百分比预算：P0 合计占主要部分，P1 承担必要连接和关键情绪，非重点的定位/呼吸合计不得超过 15%，每章合计 100%。预算不是字数任务；它决定模型把哪一部分写成可见行动、反馈和情绪压力，哪一部分必须压缩。

成文后、交付前在同一会话内逐句自检：每句至少推进剧情事实、选择、关系/状态变化，或使人物/读者情绪压力发生可辨认变化；两者皆无就删除或并入有效句。每个词也必须服务其所在句的剧情或情绪作用。修辞、气氛、顺口和“更有画面”不能独立成为保留理由；只有它们实际增强了该句的剧情理解或情绪压力才保留。重点已成立后，不得再用同义解释、动作或意象重复兑现。

但删除测试必须晚于重点闭环核销：每个高预算 P0/P1 先保有触发→人物回应→反馈→可见新状态，情绪重点还要有具体刺激、外化或余波。闭环里的句子分别承担剧情或情绪功能，不能为追求短而压成事件清单；预算不足时只补已计划闭环的缺环。

这条生产合同优先于本 Skill 中把声音、节拍、氛围或主题列为可保留功能的宽泛表述：这些元素只有在本次文本中实际推动剧情或煽动情绪时才可占用篇幅。

本 Skill 的直接写作模式也不得把“理解大纲、安排重点、补因果、写正文、自检”压成一次生成。先形成并检查以下过程产物，再写作：

1. `focus-brief.md`：当前章核心目的、P0/P1、硬事实、知识停点和退出状态；
2. `scene-plan.md`：P0 的兑现位置，以及每个场景的触发、回应、反馈和新状态；
3. `plan-gate.md`：核销每个 P0 是否保留原定人物、发生方式、对象/渠道和结果；
4. `draft.md`：仅依据通过的计划完成正文；
5. `draft-reconciliation.md`：把 P0、关键对白和退出状态映射回正文，并执行事实与删除测试。

自动化时逐项保存；普通交互只交付正文但不得跳过。计划缺失回到大纲，计划正确而正文遗漏才返工正文；多章任务仍优先改用分章隔离流水线。

## 模式路由

先判断任务是否需要分章生产：

- 单章一次性写作，且不存在需要隔离的后文答案：可以继续使用本 Skill 直接写作。
- 两章及以上、全文写作、跨模型生产，或故事依赖延迟揭示与反转：必须切换到分章隔离流水线。

分章隔离流水线中：

1. 总控端使用 `zhihu-salt-chapter-packet` 读取完整大纲，为当前章节编译无剧透执行包，并在章后审核、更新状态账本。
2. 正文模型只加载 `zhihu-salt-chapter-drafter` 和当前章节执行包。
3. 完整大纲、未来章节、私有反转说明和全部历史正文不得进入正文模型上下文。
4. 未验收章节不得进入状态账本，也不得作为后章事实来源。

不要把本 Skill 与完整大纲一并交给外部模型逐章续写；“提示模型不要泄密”不能替代上下文隔离。

## 写作前按需读取

以下要求只适用于直接写作模式；分章隔离模式由章节执行包替代：

1. 完整大纲。
2. 用户提供的参考文本；文本过长时，至少读完对应章节、关键转折和结局，避免只模仿开篇表面。
3. 写知乎盐选短篇时，读取 [references/style-routing.md](references/style-routing.md)。
4. 写两章及以上，或正文调用此前的人物认知、对象、承诺、关系及未完成动作时，读取 [references/global-continuity.md](references/global-continuity.md)。
5. 核心因果依赖现实制度、专业流程、公开规则或设备行为时，读取 [references/reality-constraints.md](references/reality-constraints.md)。

只加载与本故事相关的专项检查。故事不含取证、平台、程序性结论或对峙供述时，不执行相应机制，也不主动补入这些元素。

## 建立本次写作契约

动笔前在内部冻结以下内容，不向用户输出：

```text
硬事实与禁止改动项
叙述人称 / 视角范围 / 叙述时点 / 信息距离
主要阅读动力与辅助阅读动力
每章不可遗漏的功能单元
概述与细写的分配
参考节奏、段落颗粒、对白密度、旁白距离和留白方式
对话驱动章的对白执行计划：参考分布、主要说话人、不可概述的轮次链与允许旁白位置
叙述者立场、主要人物话语身份、必须直写/可以概述的对白边界
社会语域、称谓、口语密度、粗粝度，以及必须直写的叙述者偏见/价值判断
必须成对保留的动作—话语、认知—执念或公开—私下反差信号
人物情绪执行链：刺激、克制/阻滞、泄露、触发、宣泄或延期、余波
读者压力曲线：已知/期待、加压、到峰、释放或延期、残余动力
语言呼吸：句内功能密度、长短句分布、必须独立落地的动作/判断/转折
人物、信息、对象、关系、时间、环境与未完成动作的初始状态
现实机制替换后的统一执行事实（若有）
```

### 优先级

1. 用户明确要求。
2. 大纲硬事实与本章功能。
3. 已经写入正文的连续状态。
4. 参考文本的功能、速度、密度与表达距离。
5. 通用写作建议和量化指标。

规则冲突时按此顺序处理。量化指标不能覆盖语义完整、人物逻辑和现实可行性。

### 章节重点先于铺陈

每章动笔前先读取大纲中的唯一“章节核心目的”和全部 P0 ID，再读取 P1、P2。执行顺序固定为：

1. 先让 P0 在行动、对白、证据、选择或结果中真正发生；不能只提到，也不能用功能相近的桥段替代。
2. 用 P1 建立触发、推进、反转和结算，使 P0 产生章节后果。
3. P2 只负责承载人物、情绪、必要定位、声音和参考节拍；不得抢占章节重点或补造新的故事事实。
4. 章末逐项核销 P0 ID 和退出状态。任何 P0 未兑现时，先修重点，不以景物、心理、动作或解释补足篇幅。
5. 输出前逐字执行大纲的公开输出合同：目标标题不得复用参考标题，章节标记不得被全文连贯性吞掉。

篇幅不平均分给大纲各栏。文字集中在本章主要阅读动力和不可替代的变化上；辅助信息只有在服务 P0/P1、人物声音或目标节拍时才展开。

数字、专名、楼层、距离、时刻、器材参数、路线和证据技术参数实行硬事实白名单。大纲未授权时使用中性表达或删除；“更具体”“更真实”“更有画面”不能授权新增精确信息。

## 参考驱动，但不被样本绑架

- 有参考：提取开篇方式、信息释放速度、概述/场景比例、逐章对白结构与密度、段落长度分布、对白功能、叙述立场、人物话语身份、情绪外化方式、语言呼吸、留白和章尾承接方式。
- 无参考：依据大纲的主要阅读动力选择写法，不默认快叙、第一人称、强反转或爽文结构。
- 常见叙事模式只是路由样例，不是穷尽分类。允许低冲突成长、日常观察、喜剧、见证式主角、开放式结尾及其他有效形态。
- 只迁移结构功能，不迁移题材名词、职业身份、冲突机制、证据类型或人物关系模板。
- 参考中的明显逻辑错误、现实错误和病句不属于文风，不复制。

## 先完整，后精简

### 一、列出功能单元

每章只列大纲实际要求且不可遗漏的单元。例如事件变化、人物认识、关系位移、情绪积累、氛围转折、信息揭示、喜剧落点或主题回声。不要预设每章必须有证据、反派、反转、关系回报或强钩子。

### 二、完整兑现

1. 为每个单元写出足以成立的原因、过程或反应。
2. 因果桥、人物选择、关系变化和关键体验不能只剩作者式结果摘要。
3. 相似事件只有在刺激对象、人物含义、现实边界、后果和阅读功能都相同时才能合并；任一项发生升级，就保留最短但完整的一阶。
4. 前史、程序和移动可以概述；若压缩会损害本故事的主要阅读价值，就细写。判断维度可含因果、人物、关系、体验、氛围、悬念、喜剧或主题，不设固定项数。

完整兑现不等于逐栏场景化。概述也可以完整；不得把每个功能单元自动扩成场景，或按大纲表格顺序逐栏翻译成句子和段落。同一动作、对白或决定可以同时完成多个约束。

### 三、删除重复

功能已经成立后，再逐句逐词做删除测试：

```text
删掉它，读者对事件、人物、关系、体验、氛围、信息、规则、节拍、声音或主题的必要理解是否受损？
它是否提供相邻表达没有提供的新层次、转折、对照或后果？
```

- 两个答案都是否定：删除。
- 只有短语有效：保留必要意思，重写整句。
- 相邻表达只是同义复述：保留更具体、更准确或更符合声音的一次。
- 动作、对白或意象已经完成表达：删除随后的解释性翻译；若后一句产生新层次或新后果，则保留。
- 必要的语气词、停顿、反复和环境可以承担声音或节拍功能，不因类别被机械删除。
- 过渡只写读者理解时空、因果或动作所必需的最短部分。

删除测试必须在 P0/P1 核销之后执行，不能为了“惜字”删除章节成立所必需的重点。对每段先问它服务哪个 P0/P1，或是否独立改变人物、关系、必要情绪/读者压力、因果交接、声音和参考节拍；均不成立时删除或并入承担功能的段落。不要用“有画面感”“更真实”“更文学”作为单独保留理由。

## 最小充分表述

- 不先宣布“我要想、说、看见什么”，直接进入有内容的动作、话语或观察。
- 不先用否定句判断，再用肯定句重说同一结论。
- 并列动作、身体反应、景物、形容词或例子若只证明同一状态，保留最有效的一项；若分别承担节拍、升级或人物声音，可并存。
- 精确数字、地点、时长、来源和方位只有在影响事实、体验、规则、节拍或后续理解时才精确。
- 大纲未给具体地点时，使用不制造新事实的中性定位，不擅自把“尸体旁、路上、屋外”等改成村口、桥下、某楼层等具体地点；地点具体化会改变路线、目击和场景连续性，不属于无害画面补充。
- 细节不因“具体”自动有用，也不因“不推进外部事件”自动无用。它必须支撑本故事的目标模式、人物体验或后续理解。
- 新增参考和大纲之外的具体设定前，确认它不会制造后续义务、现实矛盾或题材偏移。
- 允许创造局部闭合的最小动作、语气或感官载体来兑现大纲规定的声音和情绪；它必须在当前场景完成作用，不能暗中新增人物身份、前史、动机、证据或跨章伏笔。
- “大家都认为”“从此每次”“多年从未”等集体共识、频率、持续时长和人生经历不是局部载体，会建立新的全局事实；大纲没有明确规定时不得补写。
- 停手、欲言又止、回避目光等微动作若会暗示人物已知秘密、犹豫动机、预谋或关系变化，也属于证据/动机设定，不能以“只是小动作”为由擅自增加。

以下词组仅在充当无信息搭台句时删，不做词面封禁：

```text
那一刻 / 就在这时 / 我想起了 / 我看见 / 我听见
我意识到 / 接下来 / 这意味着
```

## 视角与信息契约

写作前锁定叙述人称、视角范围、叙述时点和允许的信息距离。

- 叙述不得越过所选契约。第三人称限知不能擅入他人内心；多视角必须有清楚的切换边界；回忆性第一人称可以有后见之明，但要与当时认知区分。
- 分开管理“角色何时知道”和“读者何时获知”。可以延后揭示，不得让角色为隐藏反转而假装不知道自己明确知道的事。
- 事实性判断要有来源：既有知识、当下感知、可靠转述、文内规则或明确标注的推测。
- 人物可以在机制未明时采取防御或试探；正确行动不等于真相已经证实。
- 对话、文件名称、制度术语和对象标签也可能提前泄露信息，和旁白一起审计。
- 正文不使用“上一章、下一章、第几章”等创作结构标签回指人物生活，除非作品本身是元叙事。

只有采用限知视角、悬疑发现或延迟揭示时，才逐项建立“章首已知—本章新信息—允许推断—禁止结论”；其他视角按其契约执行，不套用限知模板。

## 场景、对话与情绪

### 场景

- 场景必须有当前任务：冲突、体验、关系、发现、氛围、喜剧或其他大纲功能。
- 人物、对象、信息源和环境条件先建立，再被调用或改变。
- 动作写清主体、对象、位置与结果；跳时或换场前，闭合仍会影响下一场的在场人物、对象和未完成动作，或让下一章从该动作继续。
- 异常物理、设备或世界机制必须先有可感知、可推断或事后可验证的依据。

### 对话

- 每段对白至少增加冲突、潜台词、人物、关系、信息、选择或节拍中的一项。
- 只有参考或大纲把本章定义为对话驱动章时，按对白执行计划先写完整的轮次链，再补最少旁白。不得把连续问答、交锋或共同推演缩成“某人说明/两人讨论/她答应了”。
- 对话驱动章的旁白只承担场景定位、动作可见性、信息来源、短暂停顿或对白无法承载的最短内在反应；它不能替代计划中的质问、反驳、封堵、承认、改口或决定。
- 用对应参考章的对白密度和轮次分布诊断结果，而不是设置通用比例。若生成稿明显更低，先恢复被摘要的说话轮次和回应链，不用增加心理、景物或解释凑篇幅。
- 一人连续说明可保留多个句群，前提是每个句群都推进事实、推理或压力；对方的回应必须改变下一轮的方向、问题或关系，避免“讲座式”独白。
- 寒暄、确认和重复问答压到最短，但含蓄关系、喜剧停顿和试探不按固定轮数删除。
- 人物的披露方式必须符合其目标和压力。违背自身利益的关键说法需要误判、交换、情绪失控、证据压力或主动选择等依据。
- 大纲或参考若把某句话的功能定义为身份、权力关系、价值判断、情绪泄露或宣泄，就必须直接写出符合人物口吻的话，不能改成“他骂了几句”“她解释了一番”之类摘要。
- 保持大纲规定的社会语域、称谓、礼貌等级、口语密度和粗粝度。不得把侮辱、父权、职业黑话或底层口语自动润色成理性书面表达，也不得为追求刺激擅自升级脏话或冒犯强度。
- 粗粝度也包含标记密度。大纲只要求一个辱称或一个权力标记时，不在同一句叠加多个同义辱称、脏话和感叹来“加强味道”。
- 动作与对白可连续完成同一情绪节点：动作先让情绪可见，对白再增加对象、原因、价值判断、关系权力、决定或后果。若对白只翻译动作，删掉；若动作只重复对白，也删掉。
- 若相邻章节连续依赖同一种揭示方式，检查是否单调；只在削弱阅读效果时改换，不做机械禁令。

### 情绪与体验

- 情绪来自具体刺激、关系和身体处境。先让它通过动作、对白、选择、沉默、停顿、感官或叙述判断发生，不用“他很愤怒”“我很难过”代替过程。
- 情绪词不是禁词。只有当它增加动作和对白无法提供的新判断、反差、转折或自我认知时才保留；若只是替读者解释已经看见的情绪，就删除。
- 叙述者直接评价人物、关系、处境或自己时，先判断它是否暴露叙述身份、道德立场、偏见、自我欺骗或后续反转基线。若是，保留其锋利和主观性；“藏情绪”不能把它改写成中性新闻摘要。
- 一个计划中的叙述判断默认只兑现一次。只有后一句增加新的对象、证据、时间层、道德立场或行动后果时才再次评价；不能把同一“某人冷血/我很愧疚”拆成现场一句、总结一句重复加码。
- 反差信号必须两侧同时存在：哭着说冷话、记不清人却记得某物、公开拒绝却私下保护等不一致，往往承担人物复杂性、悬念或伏笔。不能只留下更刺激的台词，也不能用旁白标签把矛盾解释成单一情绪。
- 动作、对白、感官、旁白和意象可以共同表达，但每次叠加必须带来新的对象、原因、关系层级、价值判断、选择、反差或后果。
- 只有会改变人物选择、关系、行动意志，或形成跨场未结状态的情绪，才算强情绪节点；瞬时感受用最短载体完成，不单独扩写宣泄与余波。
- 每个强情绪节点必须在正文中得到一种结算：当场宣泄，或有依据地延期。延期要让读者看见人物为何压住、压住时泄露了什么，并把未结算状态写入后续账本；不能用戛然而止冒充克制。
- 沉默只有在迫使对方反应、改变关系、形成决定、推动行动或改变读者判断时才算有效结算。
- 宣泄服从人物和题材，可以是话语、行动、拒绝、承认、决定、仪式、笑点、崩溃或安静的选择，不默认争吵、哭喊或长篇独白。
- 关键变化后保留与目标模式相称的反应或余波；长度服从人物、参考和章节功能。
- 若强事件本身已经完成大纲规定的释放或阅读回报，可以直接停，不强加总结、金句或最后念头；若人物反应有意留到后文，则按“延期”登记并保留后续触发，不得用硬切绕过情绪收据。

### 读者压力

- 人物情绪和读者压力分开管理。人物越克制，读者压力可能越高；人物完成宣泄后，事件后果又可能制造新的压力。
- 按大纲用连续的新刺激、意义升级、预期延迟或关系变化加压，不用旁白反复宣布“气氛更紧张”。
- 到峰后给出与故事模式相称的阅读回报：话说出口、行动落地、关系确认、误会刺破、真相揭开、笑点兑现或损失被承认。
- 本章若选择延期，不必强行释放，但必须留下清楚的残余问题、未完成决定或新的阅读动力。

## 语言呼吸

- 断句服从语义和节拍，不使用统一字数上限。高压、快叙或信息转折处，通常一句只承担一个核心动作、判断或信息变化；舒缓反思、连续动作和有意蓄势可以使用较长句。
- 一句话若同时塞入时间、地点、感知入口、人物动作、前史和解释，优先拆开，让最重要的动作或判断单独落地。
- 精确日期或标题式时间锚点已经独立承担定位功能时，通常在此处句止；相对时间、环境状态和人物感知/动作另起一句。尤其避免把“日期＋星期＋天色/时段＋我听见/看见＋他人动作”压成一个句子。
- 具体动作或可见后果已经让失败、羞辱、恐惧或关系变化成立时，不再追加同义的抽象翻译。只有叙述者评价能增加偏见、自责、道德立场或新的选择时才另写，并让它承担独立作用。
- 程度副词、方式副词、惯用身体反应和“突然/毫无预兆”式反应提示，只有改变时序、因果、人物控制程度或声音时才保留；不能用它们替代更准确的动作。
- 主句迟迟不出现、读者需要回读才能确认谁做了什么，或朗读时找不到自然停顿，就拆句或改序。
- 人物开口、关系转折、关键动作、信息翻面和情绪落点可以独立成段；同一主体的连续微动作没有独立落点时不要机械分段。
- 长短句与段落疏密要形成变化。短句用于承压和落点，不把全章切成等长碎句；长句用于连续性和蓄势，不把多个独立功能硬粘在一起。

## 信息发生、获知与叙述时点

- 分开管理事实发生的时点、视角人物获知的时点和正文叙述的时点。后来获知的警方结论、口供、信件、消息或转述，不得因章节压缩被改写成原场景内即时发生的对白或反应。
- 每个“过了 N 年/月/天”都标明起点和终点，并放在时间仍向前推进的位置。叙述已经到达较晚事件后，不得再用“过了 N 年”回指较早事件，造成时间表面倒流；需要回算时直接写“距某事 N 年”。
- 回到旧场景前后，用最短时态或来源标记完成切换；不能让当前人物对未来才获知的信息作出反应。
- 章节若故意延后解释触发物唤起的记忆、人物得出判断的过程或钩子答案，只写大纲允许的触发、可见反应和决定。不得用“记忆里藏着线索”“我似乎抓住了关键”之类抽象占位句替作者解释保留机制。

## 细节生命周期

物件、数字、动作、记忆、意象和感官细节可以一次性完成当前功能，也可以跨章延续；不强迫首尾呼应。

回指旧细节前检查：

1. 状态连续：它在时间、位置、归属、可访问性和物理状态上仍可抵达。
2. 当前触发：此刻的观察、行动、关系或处境足以触发它。
3. 当前结果：回指带来新的理解、体验、行动、关系、节拍或主题效果。

必要条件缺失时，删掉回指、改用已有状态，或在首次发生处补入同时服务当章的最短前置。不能只因“前文写过”就回收。

## 多章与全文连续性

两章及以上时，优先使用分章隔离流水线。以已经验收并写入正文的事实维护状态账本。大纲规定意图，正文建立事实；后章不能继承只存在于作者计划中的状态。

- 每章更新人物、信息、对象、关系、时间/程序、环境及未完成动作。
- 先审核当前章，再更新账本，再编译下一章；不得把顺序合并成一次模型调用。
- 后章正文模型只读压缩后的章首账本和最短承接片段，不读取全部历史正文。
- 后章使用“那次、之前、再次、仍然、早已”等回指前，定位前章实际锚点，确认状态如何产生、持续、转移及为何当前可调用。
- 否定句和假设句同样可能断言某状态存在，照常检查来源。
- 人物改变态度、目标、阵营、位置、持有权或访问权时，写出足以成立的触发和交接。
- 以一个明确场景为 `T0`，把“明天、后天、第三天、四周后”等相对时间换算到同一日序/时刻，再检查先后与重叠；未写明跳时默认连续。
- 时间状态同时包含人物可用性与持续承诺。请假、工作、旅行、住院、照护、等待和程序耗时必须覆盖人物实际在场区间；长跳时后重新核对仍有效的安排。
- 每章末清算在场实体和未完成动作；跨章悬停时，下一章从相容状态继续。
- 修改前章后，重新审计受影响的后章。
- 全文完成后先从前向后检查状态可达，再从结尾向前定位回收、转折和兑现的正文锚点。

涉及可验证材料、数字系统或程序性结论时，再执行专项来源、访问层级、真实性与程序先后检查；没有这些机制的故事不补入它们。

## 现实与世界规则

- 现实题材中，只核查会决定标题、主线、人物选择或结局的外部主张。
- 真实制度、专业流程、公开范围、设备行为和合理耗时必须可行；不确定时查可靠来源、改成宽表述、虚构机构或替换机制。
- 架空题材不套现实制度，但世界规则必须前后一致，能力与代价不能为单次反转临时变化。
- 大纲机制不成立时，保留其叙事功能，替换因果桥，并把统一后的事实同步到标题、伏笔和全部章节。
- 角色明显放弃更简单路径时，正文要给出与核心目标相关的收益、代价或限制。

## 章节长度、段落与章尾

- 用户或大纲的明确篇幅要求优先。
- 有结构可比的参考章节时，测量字数、段落、平均段长和对白比例，用于定位差异；允许范围由任务、参考波动和章节功能决定，不使用通用固定门槛。
- 章节功能不对应时，不按序号强行一一配长。
- 不为接近数字补心理、景物、动作或回忆，也不因指标接近就删除必要功能。
- 段落颗粒服从参考的**分布**和场景语义，不把“短段快叙”翻译成每句都单独成段。总字数变化时，同时对照平均/中位段长与按字数比例缩放后的段落量。
- 同一主体、同一动作链或同一观察尚未形成独立落点时合在一段；新事实、转折、对白落点、节拍停顿或后果需要单独承压时再断段。
- 快叙可以短段落锤，沉浸场景保持动作与对白连续。连续三段以上都很短时，逐项确认每个空行是否真的制造了不同节拍；没有就合并。
- 在本章最有承接力的位置结束。可以是局势变化、决定、问题、答案、情绪余波、意象回声、关系位移、喜剧落点或阶段性闭合。
- 章尾类型由本故事的阅读动力决定，不要求每章以威胁、证据、反转或未答问题收钩。
- 参考文本只有数字编号或无标题时沿用其形式，不擅自添加解释性章名。用户要求新拟标题时，标题不得提前回答正文末尾才提出的疑问，也不得把风险假设写成事实。

需要量化时可运行：

```powershell
./scripts/story_metrics.ps1 -Path <正文> -ReferencePath <参考>

# 仅当章节确实一一对应且任务明确采用这些容差时：
./scripts/story_metrics.ps1 -Path <正文> -ReferencePath <参考> -CompareChapters -HanTolerance 0.15 -ParagraphTolerance 0.20
```

脚本默认只提供描述指标和复查提示。只有参考结构可比且任务明确给出容差时，才传入比较参数；统计结果不能替代语义审计。

## 表层校对

交付前逐项检查：

- 标题、身份、数量、等级、时间、地点、专名和结果与正文一致，不为增强冲击擅自升级。
- 时序词有前置状态；动作次数、接触顺序和空间结果只有合理解释。
- 主谓宾、动宾搭配、比较对象、指代和长句成分自然明确。
- 角色语言符合身份、处境、关系和当下目标。
- 写作分析术语、提示词和项目管理语言没有无故进入人物语言；题材内合法用词不因词面相同被误删。
- 比喻、排比、金句和留白服务当前功能，不按数量机械判定好坏。

## 完稿流程

直接写作单章时：

1. 读取大纲、参考和所需专项 reference。
2. 冻结写作契约与统一执行事实。
3. 列出本章不可遗漏的动态功能单元。
4. 完成当前章。

分章生产多章或全文时：

1. 在总控端读取完整大纲并建立私有蓝图。
2. 编译当前章执行包。
3. 让单章正文模型只凭执行包写作。
4. 总控端审核；返修稿仍只接收安全返修单。
5. 通过后更新状态账本，再编译下一章。

两种模式都继续执行：

- 检查人物情绪执行链和读者压力曲线：刺激是否连续，宣泄或延期是否有依据，余波是否可见。
- 检查声音载体：该直写的对白是否被摘要，动作、话语和关系是否统一。
- 再检查功能覆盖、人物选择、视角和状态可达。
- 执行逐句逐词删除测试，删除重复，不删除必要的声音、情绪节点和阅读回报。
- 从头到尾做前向连续性审计。
- 从结尾向前做回收与兑现审计。
- 按需做现实机制或世界规则审计。
- 做语言呼吸、标题、事实、句法、搭配和指代校对。
- 可选运行指标脚本定位异常；人工判断其是否真是问题。
- 只交付用户要求的正文或文件。

## 输出格式

完整正文：

```markdown
# 故事标题

## 第一章 标题

正文
```

单章任务只输出该章标题与正文。用户要求文件时，创建独立 Markdown 文件并保留大纲。

## 终稿自检

- 开篇是否尽快兑现本故事自己的阅读承诺，而非套用通用刺激场景？
- 人称、视角范围、叙述时点和信息距离是否始终一致？
- 每章不可遗漏的功能单元是否完整，删减后是否仍成立？
- 每个表达单元是否承担本故事需要的功能；是否仍有无增量复述和搭台句？
- 人物、关系、体验、氛围、喜剧节拍、声音和主题是否被误当成“无情节”而删坏？
- 场景中的人物、对象、信息源、环境和未完成动作是否连续可达？
- 多章回指是否能定位正文锚点，而非只在大纲里存在？
- 人物知识与读者揭示是否符合视角契约？
- 人物选择、态度变化和关键披露是否符合其目标、压力和关系？
- 人物情绪是否主要藏在动作、对白、选择、停顿或感官里；直接情绪词是否确实增加新层次，而非替读者翻译？
- 强情绪节点是否完成宣泄或有依据地延期；延期时是否保留了泄露、未结算状态和后续触发，宣泄后是否有最短余波？
- 读者压力是否经历可辨认的积累、到峰、释放或延期，并获得阅读回报或明确的新动力？
- 承担身份、关系权力、价值判断或情绪宣泄的对白是否被直接写出；动作与对白叠加时是否各自提供新信息？
- 对话驱动章是否先兑现了大纲的对白执行计划；对白密度与轮次是否仍接近对应参考章的功能分布，还是被旁白“某人说/两人讨论”替代？
- 叙述者有功能的偏见、道德判断和自我判断是否被保住；社会语域和粗粝度是否没有被中性化或无依据升级？
- 一个计划判断是否被拆成多句同义评价；粗粝对白是否叠加了超过大纲强度/密度的辱称和脏话？
- 必须成对保留的反差信号是否只剩动作或只剩话语，导致人物复杂性、伏笔或误判消失？
- 是否擅自新增了集体共识、长期频率、持续时长、人生经历，或用暗示秘密/动机的微动作补“画面感”？
- 是否把大纲未指定的中性地点擅自具体化，制造了路线、目击或场景连续性新事实；每个相对时长是否有正确起止点且叙述方向清楚？
- 具体后果之后是否仍跟着同义抽象解释；无功能的程度副词、惯用反应提示和身体反应是否已删除？
- 精确日期/标题式时间锚点是否与相对时间、感知入口和人物动作挤在一句；后来获知的信息是否被错写成现场即时对白；故意保留的推理机制是否被抽象占位句提前命名？
- 现实机制或架空规则是否足以支撑核心因果？
- 旧细节是否同时满足状态连续、当前触发和当前结果；无用回扣是否已删除？
