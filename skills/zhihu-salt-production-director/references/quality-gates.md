# 总控质量门槛

## 节点通用门槛

- 输入产物 ID、版本、哈希和状态可验证。
- 节点只读取允许输入。
- 输出符合节点注册类型及对应 schema。
- 结构化控制器通过；退出码或模型自报不算通过。
- 输出没有覆盖旧版本，失败证据仍可追溯。
- 登记产物位于 run 内不可变证据库；工作路径重跑或覆盖不改变历史哈希。
- 研发参考的原文锚点和内容切片没有越过总控私有层进入生产节点。

## 单章进入账本

- 正文前必须存在已接受的重点卡、场景计划和计划门禁；每个 P0 都在计划中保留原定人物、发生方式、对象/渠道和结果，并有唯一的兑现单元。
- 审核必须按固定顺序执行，不得先做整体印象评分：`P0 核心信息 → P1 关键节点与章节退出状态 → 硬事实/连续性 → 文字功能 → 仿写节拍`。
- 每个 P0 ID 都有正文锚点，且在行动、对白、证据、选择或结果中真正发生；近似桥段、旁白提到或“整体意思相同”不能替代。任一 P0 缺失或错误直接拒绝。
- P1 的触发、推进、反转和结算围绕 P0 形成因果链；辅助信息没有被平均铺开后抢占主功能。
- 边界、硬事实和知识时点正确。
- 高权重场景完成触发、回应、反馈和新状态。
- 未授权故事事实、未来泄露和控制语言为零。蓝图锁定人物、因果、时序、数量、身份、证据、程序结果和跨章状态；不改变这些事实且承担明确功能的局部感官、比喻、语气、微动作和普通材质属于正文表达空间，不得按“蓝图未逐字授权”误杀。
- 每个正文段能归属到 P0/P1、人物、关系、必要情绪/读者压力、因果交接、人物声音或参考节拍；仅装饰、同义解释、无后果精确细节和证明“写得真实”的段落拒绝进入账本。
- 人物位置、物件持有、关系、伤病和未完成动作连续。
- 语义审核引文、段落覆盖和正文哈希通过。
- 篇幅来自授权内容；完整洁净稿可由总控回估错误旧范围。

## 全文进入终审

- 所有正式章节都有当前有效的通过审核及状态账本。
- 章节顺序、标题和合并边界正确。
- 前向连续性、反向回收、知识与视角审计通过。
- 没有静默丢失的活跃状态、悬空物件或控制字段泄漏。
- 参考模式完成重合与依赖审计；原创模式不依赖参考原文。
- 最终总控通读完成。
- 模型、成本、耗时、返修和人工介入记录完整。

## 一票否决

- 伪造、缺失或不可复算的审核证据。
- 开放打回决策尚未解决。
- 指定交付产物失效或待复审。
- 核心因果、结局、硬事实或现实机制不成立。
- 未来信息提前泄露。
- 全文审计不是明确通过。
- 以文笔优点、自动分数或模型自评抵消硬错误。
