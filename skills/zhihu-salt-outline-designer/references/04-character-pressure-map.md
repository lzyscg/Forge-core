# 第 4 轮：人物与压力

本轮唯一任务是提取人物行动逻辑、关系变化、人物情绪和读者压力，不修改事件顺序，不设计文风。

输出 `character-pressure-map.md`，逐章记录：

- 主要人物当下目标、阻碍、防御与策略；
- 人物关系和权力位置发生了什么变化；
- 人物情绪链：具体刺激 → 冲动/判断 → 克制/阻滞 → 泄露载体 → 触发 → 宣泄/延期 → 可见余波；
- 读者压力链：已知/期待 → 新刺激与意义升级 → 预期出口 → 到峰 → 释放/延期 → 残余问题；
- 每个不可逆事件的最短情绪收据；
- 延期情绪的后续结算触发。

人物情绪和读者压力必须分开。同方向情绪若损失对象、关系含义或不可逆程度不同，不得合并；人物可以压住情绪而读者压力继续上升。
