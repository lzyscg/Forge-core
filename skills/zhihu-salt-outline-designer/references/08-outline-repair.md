# 第 8 轮：定点返修

本轮唯一任务是执行自检中已经列明的修复，不做自由润色。

先按 `earliest_stage` 路由：

- `boundaries`：删除或归位跨章事件，并同步受影响字段；
- `facts`：修事实与冲突账本；
- `story_change`：修章节变化、因果、P0、反转或退出状态；
- `character_pressure`：修人物策略、情绪收据或读者压力；
- `narrative_fingerprint`：修声音、对白、详略或语言呼吸；
- `assembly`：只修缺字段、错标签和排版合同。

修排版合同时必须保留字面标记 `## 分章执行卡`，并允许后续章节卡继续使用同级 `## 00｜…`；不要为追求 Markdown 嵌套美观而删除该标记。

每章必须保留独立的 `### 章末钩子`，并确保 P0 含 `[FACT @Lx-Ly]` 或 `[OBS @Lx-Ly]` 来源标签。

冷开场 P0 不得写“无”，且只能概括冷开场自身源行；同时删除任何越过当前章节源行边界的倒灌细节。

只重做被打回的阶段及其下游组装，不改动已通过的上游产物。不得用原创内容填补遗漏，不得把编号章节事件移到冷开场或其他章节。完成后重新运行结构门禁和第 7 轮自检；两者都通过才可交付。
