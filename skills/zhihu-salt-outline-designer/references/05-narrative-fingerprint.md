# 第 5 轮：声音与节拍

本轮唯一任务是提取原文如何讲述，不改变故事事实、章节变化和情绪链。

输出 `narrative-fingerprint.md`：

- 第一行与前 300 字的开篇功能；
- 逐章快叙、完整场景、对白、独白和留白的比例与主要载体；
- 叙述视角、时点、距离、叙述者立场、偏见、道德判断和反讽对象；
- 主要人物的称呼、口语密度、礼貌/侮辱强度，以及施压、回避、示弱、命令、自辩等话语策略；
- 对白驱动章的轮次：谁回应谁、每轮新增事实/压力/关系位移、不可概述落点；
- 每章段落密度、长短句交替、新信息速度、细写和压缩位置；
- 留白、反差信号、语言呼吸与章尾收钩方式。

题材名词不是文风。只迁移叙事功能和强度，不复制原文大段独特句子，也不把粗粝冲突统一润色成中性书面语。
