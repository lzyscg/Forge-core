# 第 1 轮：来源与边界

本轮唯一任务是确认输入完整并建立章节边界，不提炼主题、情绪、文风或正文计划。

输出 `source-boundaries.md`，除元数据和阻塞原因外使用一行一个边界的紧凑表格：

1. 源文件标识、总行数、总字符数和完整性判断；
2. 冷开场及每个原章节的叙事顺序、公开标签、源行/字符范围、首尾短锚点；
3. 每章非空段数、近似字符数和直接引语段落占比；
4. 原标题、原章节数量、原编号/标题形式；
5. 任何无法切分、缺页、截断、标签冲突或重复边界。

一个源边界只能对应一张章节执行卡。不得合并、补号、重切或把编号章节事件移入冷开场。输入不完整或边界不唯一时输出 `BLOCKED`，不进入下一轮。
