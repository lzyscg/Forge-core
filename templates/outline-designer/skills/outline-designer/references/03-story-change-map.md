# 第 3 轮：故事变化

本轮唯一任务是提取故事与章节的变化链，不处理人物情绪表现和语言风格。

输出 `story-change-map.md`：

1. 一句话主线、主要阅读动力和主题价值冲突；
2. 每章一句“从……到……”的唯一变化；
3. 每章核心目的、1—3 个 P0、必要 P1、章首和退出状态；
4. 1—5 个因果节点，写明触发、行动、反馈和新状态；
5. 反转发生位置、前置事实和后果；
6. 章末钩子与下章驱动，但只能停在当章允许推断。

每个 P0 使用全篇唯一 `Bxxx-P0-n`，注明人物、发生方式、对象/渠道、结果及 `FACT/OBS` 来源。不得把后文真相倒灌为前文已知，也不得为了“更顺”移动原事件归属。
