# 第 7 轮：独立自检

本轮唯一任务是审核刚组装的大纲，不改写、不润色。

逐项核对，顺序不可交换：

1. 冷开场和原章节数量、标签、顺序、归属、首尾定位是否一致；逐字段检查本章新证据、首次揭示、因果链、细写时刻、情绪刺激、对白链、场景连续性、生命周期和章末钩子，不能只查 P0 或相信来源标签；
2. 每个 P0 是否具有同一主体、方式、对象、结果和 `FACT/OBS` 来源；
3. 知识时点是否把 `INFER/PRIVATE` 提前写成事实；
4. 人物、数字、复合结果、因果、反转和结局是否遗漏或改写；
5. 每章故事变化、人物情绪、读者压力、叙述判断、对白轮次和段落节拍是否有对应来源产物；
6. 生命周期、人物离返场、物件交接、延期情绪和信号回收是否连续；
7. 固定标题、七段执行卡和必填字段是否完整；
8. 外部结构门禁结果是否为 `pass`。

冷开场禁止使用编号章节才出现的拍肩、手指发抖、司机对白、调查组细节或其他展开。

只输出严格 JSON，不加 Markdown 代码围栏：`coverage` 按章节和维度列 `pass/reject`，`issues` 写最早责任轮、唯一证据和最小修复范围，`verdict` 为 `pass/reject`。任何阻断项或结构门禁失败都必须 reject。
