# 章节起草

## 目的

把「章节要求」与「原始素材」组织成一段连贯的第一人称章节正文，产出一份完整、可直接阅读的 Markdown 稿件。

## 输入

- 章节要求：视角、篇幅、风格与必须包含的要素。
- 原始素材：人物、处境、冲突与关键信息。

## 起草顺序

1. 先确定本章的核心冲突与第一人称叙述者的处境。
2. 用素材里的具体细节支撑情节，不虚构与素材冲突的设定。
3. 按「处境 → 触发事件 → 冲突升级 → 本章收束」的顺序展开。
4. 收束处留一个能让读者继续往下读的钩子，但本章本身必须完整。

## 连续性检查

- 叙述者的人称与身份是否全章一致（始终第一人称）。
- 时间线与因果关系是否自洽，人物动机是否前后一致。
- 已确立的设定在本章内不能被推翻。

## 返修清单（收到意见时逐条处理）

- 列出审核给出的每一条意见，逐一确认已在新稿中落实，不漏任何一条。
- 修改时保持其余部分稳定，不引入新的矛盾。
- 发布的是完整新稿，而不是只含改动的补丁。

## 终稿自检

- 是否完整覆盖章节要求点名的每个要素。
- 是否忠实使用素材、没有多余支线。
- 正文是否为完整 Markdown、从开头到收束可直接阅读。
