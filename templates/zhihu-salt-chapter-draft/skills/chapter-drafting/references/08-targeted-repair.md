# 定点返修协议

返修 Agent 先把安全返修单映射到最早责任维度：

- 重点、事实输入或预算错误：退回重点与权限轮；
- 场景顺序、闭环或转场错误：因果校正轮；
- 人物策略、对白或情绪不足：人物与情绪轮；
- 未授权事实、知识、物件或章节越界：信息与连续性轮；
- 重复、解释和无功能文字：功能压缩轮。

一次返修只处理返修单命中的维度。冻结未列入改动预算且符合执行包的文字，不顺手换词、换序或补气氛。删除越界事实时同时删除派生句；补写时明确补哪个既有闭环缺口，不新增背景、景物、回忆、程序或人物经历。

句段冻结或精确移动、替换由运行器提供机器可读的 exact-replacements 合同，并在发布前运行 `scripts/validate_repair_scope.py`；任何合同外改字都保存为失败候选并拒绝。

若同一返修单命中多个维度，按“重点/骨架 → 因果 → 人物情绪 → 信息连续性 → 压缩”顺序分轮执行，不在一个响应里同时修完。
